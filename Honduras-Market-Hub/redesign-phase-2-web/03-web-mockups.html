SABORES DE HONDURAS · WEB REDESIGN — PHASE 2

Mockups for the storefront

What changed vs current

  • Half-height hero (480 px) instead of full viewport — products are visible above the fold.
  • Persistent inline search in the desktop header (was hidden behind an icon).
  • Single primary CTA ("Comprar ahora") + one secondary text link, instead of two equal-weight buttons.
  • Gold-tinted free-shipping bar (was solid blue, low contrast against header).
  • Honduran flag stripe as the very last footer element — quiet cultural cue.
  • Newsletter strip kept; trust-and-payment summary moved to footer credit row.
